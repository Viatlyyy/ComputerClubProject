Восстановление базы ПК-клуба

Комплект содержит полный архив PostgreSQL и его текстовую копию: схема, индексы, внешние ключи, счётчики ID и все 87 строк в шести таблицах. Для публичной копии ФИО и телефоны заменены демонстрационными, пароли пользователей приложения удалены. Серверные роли и их пароли не входят в архив.

Установите PostgreSQL 18 с утилитами командной строки. Для импорта нужна роль PostgreSQL, которой разрешено создавать базы. Используйте один из двух форматов; загружать оба в одну базу не нужно.

Импорт в новую базу

В PowerShell откройте каталог с этим файлом и выполните одну из команд. Имя базы должно быть новым. Путь к утилитам при необходимости можно задать через -PgBin.

.\Импорт.ps1 -Database computer_club_demo -Format backup
.\Импорт.ps1 -Database computer_club_demo -Format sql

Скрипт восстанавливает базу и применяет обновление 001_payments.sql для оплаты и истории чеков. Прежние завершённые сеансы переходят в историю как оплаченные. Скрипт не перезаписывает существующую базу. PostgreSQL запросит пароль серверной роли, если он нужен и не настроен локально. При ошибке созданная база остаётся для проверки.

При ручном восстановлении в pgAdmin создайте пустую базу и выберите «Восстановить», формат Custom и файл ComputerClub.backup. При необходимости пропустите владельца, права и табличные пространства. После восстановления выполните 001_payments.sql в этой базе. Для обновления уже используемой базы закройте приложение, сделайте резервную копию и выполните тот же скрипт.

Пароли приложения

Пароль роли PostgreSQL служит для соединения с сервером. Пароли admin и manager служат для входа в программу. После импорта назначьте каждому пользователю свой локальный пароль в таблице public.users через редактор данных pgAdmin. Пароли в исходники и публичный репозиторий не добавляйте.

Запуск приложения

Задайте строку подключения в том же окне PowerShell. Введите значение вида Host=localhost;Port=5432;Username=postgres;Password=ваш_пароль;Database=computer_club_demo. PowerShell 7 скроет ввод.

$env:COMPUTER_CLUB_CONNECTION_STRING = Read-Host 'Строка подключения PostgreSQL' -MaskInput
Set-Location ..
dotnet run --project .\ComputerClubWinForms\ComputerClubWinForms\ComputerClubWinForms.csproj
Remove-Item Env:COMPUTER_CLUB_CONNECTION_STRING

Сборка использует .NET 8 для Windows. В интерфейсе войдите под одним из пользователей, которому назначили пароль. Для демонстрации отчётов можно выбрать период сохранённых сеансов. Просроченные сеансы закроются при входе по плановому времени окончания.
