База ПК-клуба от 21 ноября 2026 года

Свежий комплект содержит шесть таблиц, связи, индексы, счётчики ID и данные текущей версии с оплатой и историей чеков. В копии для публикации ФИО, телефоны и имена в чеках заменены демонстрационными. Даты, длительность, суммы и статусы оплаты сохранены. Для входа подготовлены учебные аккаунты.

1. Подготовка

Установите PostgreSQL 18 с утилитами командной строки и запустите сервер. Для сборки программы нужен .NET 8 для Windows. Скачайте весь репозиторий через Code → Download ZIP и распакуйте его. Все файлы каталога database должны находиться рядом.

2. Импорт

Откройте PowerShell в каталоге database и выполните одну команду. Скрипт сам создаст базу computer_club_demo, загрузит структуру и данные и проверит таблицы.

.\Импорт.ps1

Введите пароль роли PostgreSQL, заданный при установке сервера. Для текстового SQL вместо архива выполните:

.\Импорт.ps1 -Format sql

Выберите один формат. База с выбранным именем должна отсутствовать. Если требуется другое имя или сервер, укажите параметры:

.\Импорт.ps1 -Database ComputerClubUp -Server localhost -Port 5432 -User postgres
.\Импорт.ps1 -Database computer_club_demo -PgBin 'D:\PostgreSQL\18\bin'

Для запуска через PowerShell 7 можно использовать pwsh -NoProfile -File .\Импорт.ps1. Если локальная политика запрещает скрипты, откройте pgAdmin и воспользуйтесь способом ниже.

Восстановление через pgAdmin

  1. Создайте новую пустую базу, например computer_club_demo.
  2. Нажмите по ней правой кнопкой → Restore / Восстановить. Выберите Custom и файл ComputerClub.backup.
  3. В параметрах исключите восстановление владельца и прав (No owner и No privileges), запустите восстановление и дождитесь успешного завершения.
  4. Обновите дерево базы. В Schemas → public → Tables должны появиться users, clients, computers, bookings, sessions и settings.

Текущий дамп уже содержит поля оплаты и чеков. Файл 001_payments.sql нужен при обновлении старой базы, а также повторно выполняется скриптом импорта для проверки совместимости.

3. Подключение приложения

В строке подключения укажите имя именно восстановленной базы. Для примера выше это computer_club_demo. Ошибка 42P01 «отношение users не существует» означает, что приложение не видит таблицу в выбранной базе или схеме. Проверьте сервер, порт и Database, затем наличие шести таблиц в public.

В Visual Studio откройте ComputerClubWinForms/ComputerClubWinForms/Data/DatabaseHelper.cs и задайте DefaultConnectionString:

"Host=localhost;Port=5432;Username=postgres;Password=ваш_пароль;Database=computer_club_demo";

Укажите пароль PostgreSQL со своего компьютера. Если импортировали в ComputerClubUp, задайте Database=ComputerClubUp. Пересоберите и запустите проект. Учтите, что установленная переменная COMPUTER_CLUB_CONNECTION_STRING имеет приоритет над DefaultConnectionString.

Альтернативно задайте полную строку подключения в PowerShell 7 и запустите из того же окна:

$env:COMPUTER_CLUB_CONNECTION_STRING = Read-Host 'Строка подключения PostgreSQL' -MaskInput
Set-Location ..
dotnet run --project .\ComputerClubWinForms\ComputerClubWinForms\ComputerClubWinForms.csproj
Remove-Item Env:COMPUTER_CLUB_CONNECTION_STRING

4. Вход

Администратор — логин admin, пароль admin123. Сотрудник — логин manager, пароль manager123. Это опубликованные учебные аккаунты для демонстрации. При использовании базы для реальной работы назначьте собственные пароли в users.

В отчётах и истории выберите период сохранённых записей, например октябрь–ноябрь 2026 года. Сеанс по завершении переходит в «Ожидают оплаты», после подтверждения деньги учитываются в отчёте по дате оплаты. Чек открывается из истории.

Проверены оба формата импорта в новые базы, таблицы, вход обоими аккаунтами и чтение истории менеджерами приложения. Контрольные суммы файлов находятся в verification.json.
